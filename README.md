# MiningGame

MiningGame — учебная игра на Go об управлении угольной шахтой. Предприятие получает пассивный доход, нанимает шахтёров трёх классов и покупает кирки, вентиляцию и вагонетки. Цель — приобрести всё оборудование за минимальное время. Проект посвящён интерфейсам, горутинам, каналам, контексту и REST API; игровые правила описаны в [техническом задании](PROJECT_SPEC.md).

Для запуска нужен Go 1.27 или новее: выполните `go run .`, затем отправьте `POST /enterprise/beginning` на `http://localhost:8080`. Адрес можно изменить флагом `-addr`. После покупки всего оборудования `POST /enterprise/completion` возвращает статистику и завершает игру вместе с HTTP-сервером. Все данные хранятся в памяти. Маршруты и примеры запросов приведены в [описании API](API.md); проверки запускаются командами `go test ./...` и `go vet ./...`.
